# Publication readiness

**Status: INSUFFICIENT EVIDENCE.**

The code and actual blind known-answer measurements provide a useful start for
a software/method note. They do not yet support a claim of survey-wide
completeness, low false-positive probability, or a novel planet. The sample is
discovery-selected, the only null class is inverted flux, 97.2% of searches hit
the trial cap, the generated release is local/ignored, and there has been no
independent reproduction.

Before submission, publish a versioned code/data release with exact executable
and source identity; include a new locked benchmark or registered injection
suite; compare with an independent transit search at matched FAR; include real
false-positive cohorts and pixel-level validation; describe selection effects
and uncertainties; and report the cap rate and runtime. Do not use the blind
set already inspected for final tuning or final paper headline metrics.

Potential manuscript direction after those gates: a reproducible, CPU-efficient
TESS light-curve candidate-screening method with a calibrated operating point
and an openly archived benchmark. A discovery paper requires candidate-specific
external confirmation beyond this system review.
